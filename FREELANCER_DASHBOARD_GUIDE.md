# Freelancer Dashboard - Complete Guide

## 🎯 Overview

The Freelancer Dashboard is a dedicated portal for freelance workers to manage their tasks, track commissions, and view their credentials.

---

## 🚀 How to Access

### Step 1: HR Creates Freelancer Account
1. Login to HR Dashboard
2. Go to "User Management"
3. Click "Add User"
4. Select Role: **Freelancer**
5. Enter email address
6. Set commission rate (e.g., 10%)
7. Click "Create User"
8. System generates:
   - Unique ID (e.g., `FR-001`)
   - Default Password

### Step 2: Freelancer Login
1. Go to main login page
2. Click **"Freelancer"** button (teal color)
3. Enter Unique ID and Password
4. Click "Login"
5. Redirects to Freelancer Dashboard

## 📱 Dashboard Features

### 1️⃣ Task Progression Tab

**Features:**
- ✅ View all assigned tasks
- ✅ Task statistics (Total, In Progress, Completed, Pending)
- ✅ Task details with deadlines
- ✅ Progress tracking (0-100%)
- ✅ Status updates (Pending → In Progress → Completed)
- ✅ File attachments with download
- ✅ Overdue task warnings

**How to Use:**
1. Click on any task to view details
2. Click "Update Progress" button
3. Change status or adjust progress slider
4. Download attached files if any
5. Track deadlines and completion status

---

### 2️⃣ Commissions Tab

**Features:**
- 💰 Commission Rate display
- 💰 Total Earned amount
- 💰 Total Paid amount
- 💰 Pending Amount
- 📊 Monthly earnings breakdown
- 📊 Project commission history
- 📊 Payment status tracking

**What You See:**
- **Commission Rate**: Your percentage (set by HR)
- **Total Earned**: All commission from completed projects
- **Total Paid**: What you've received
- **Pending**: What's owed to you
- **Monthly Chart**: Earnings timeline
- **Project Table**: All your projects with commission amounts

---

### 3️⃣ Task Details & Submission Tab

**Features:**
- 📋 Select any assigned task
- 📄 View complete task information
- 📎 Download files from admin
- 📤 Upload your completed work
- ✅ Submit task for review
- 📝 Add submission notes

**How to Use:**
1. **Select a Task**: Click on any task card to view details
2. **View Task Info**: See title, description, status, progress, deadline
3. **Download Admin Files**: Download any attachments provided by admin
4. **Upload Your Work**: 
   - Click "Choose Files" to upload multiple files
   - Max 800KB per file
   - Supports all file types
5. **Add Notes**: Optionally add submission notes
6. **Submit**: Click "Submit Task as Completed" when done
7. **Status Update**: Use "Mark as In Progress" to update status

**Important:**
- Must upload at least one file before submitting
- Submission marks task as 100% complete
- Task sent to admin for review after submission

## 🆘 Troubleshooting

### "Invalid credentials or account not found"
- Check if HR created your account
- Verify Unique ID (case-sensitive)
- Verify password (check with HR)
- Make sure "Freelancer" button is selected

### "Access Denied"
- Ensure your role is set to "freelancer" in the system
- Contact HR to verify your account status

### "No tasks showing"
- Tasks must be assigned by HR/Admin
- Check with your manager for task assignments

### "Commission not updating"
- Commissions update when projects are marked complete
- Payment status updates when HR records payment
- Contact HR if discrepancies exist

## 🔄 Differences from Employee Dashboard

| Feature | Employee | Freelancer |
|---------|----------|------------|
| Clock In/Out | ✅ Yes | ❌ No |
| Time Tracking | ✅ Yes | ❌ No |
| Attendance | ✅ Yes | ❌ No |
| Goals | ✅ Yes | ❌ No |
| Performance | ✅ Yes | ❌ No |
| Tasks | ✅ Yes | ✅ Yes |
| Commissions | ✅ Yes | ✅ Yes |
| Credentials View | ❌ No | ✅ Yes |

**Why?**
- Freelancers work remotely/flexibly
- No need for time tracking
- Focus on task completion and commission
- Simplified, streamlined interface
